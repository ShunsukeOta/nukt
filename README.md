# nukt
Minimal responsive band website. Next.js 15 App Router / TypeScript.

## Editable content
All releases, YouTube video ID, platform links, chronology and placeholder goods are configured in src/site-data.ts.
Unknown social/video destinations remain inactive; the goods are concepts, not sale listings.

## Responsive
Uniform grids: 3 columns on desktop, 2 on tablet, 1 on mobile.
Compact menu below 820px. Reduced-motion support.

## Deploy
npm install && npm run build
Vercel framework Next.js, Node 22.x, root ./, production URL https://nukt-theta.vercel.app/
